# Mobile Project

주류 바코드 인식 및 테이스팅 노트 공유 앱입니다.

## 프로젝트 소개

이 프로젝트는 주류 바코드를 카메라로 인식해 해당 주류의 정보, 맛, 향, 리뷰를 확인할 수 있는 모바일 애플리케이션입니다.

사용자는 직접 리뷰와 테이스팅 노트를 작성할 수 있고, 다른 사용자가 남긴 리뷰도 확인할 수 있습니다.

## 서비스 핵심 흐름

```text
마트 / 편의점 / 술집
↓
술 바코드 스캔
↓
술 정보 확인
↓
리뷰 작성
↓
맛/향 데이터 축적
↓
검색 및 추천
```

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 바코드 인식 | 카메라로 주류 바코드를 스캔해 제품 정보를 조회 |
| 주류 정보 조회 | 주류명, 카테고리, 도수, 용량, 가격, 맛, 향 정보 제공 |
| 리뷰 작성 | 주류에 대한 텍스트 리뷰와 별점 작성 |
| 테이스팅 노트 | 사용자가 직접 시음 기록을 작성하고 공유 |
| 리뷰 확인 | 다른 사용자가 작성한 리뷰 확인 |
| 맛/향 데이터 축적 | 리뷰와 노트를 통해 Taste/Scent 데이터 수집 |

## API 엔드포인트

| 경로 | 설명 |
| --- | --- |
| `/alcohols/*` | 주류 정보 관련 API |
| `/review/*` | 리뷰 관련 API |
| `/tastenote/*` | 테이스팅 노트 관련 API |
| `/members/*` | 회원 관리 API |

상세 API는 [API.md](API.md)를 참고하세요.
